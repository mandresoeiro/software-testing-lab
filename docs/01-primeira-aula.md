# Primeira Aula - Conceitos de Testes de Software

## Objetivo da aula

Entender, com palavras simples, por que testamos software.

## Explicacao simples

Testar software e verificar se o sistema faz aquilo que deveria fazer.

Um teste ajuda a responder perguntas como:

- a funcionalidade funciona?
- o sistema se comporta bem quando algo da errado?
- uma mudanca quebrou algo que antes funcionava?
- existe evidencia de que aquilo foi conferido?

## Ligacao com o projeto

Neste projeto, cada conceito estudado deve virar uma pequena pratica.

Primeiro conceito pratico:

```text
TestCase
```

Um `TestCase` e um roteiro de verificacao.

Ele descreve:

- o que sera testado;
- quais passos devem ser executados;
- qual resultado e esperado.

## Evidencia esperada

Depois desta aula, a primeira evidencia pode ser:

- README criado;
- primeira tela do projeto;
- primeiro modelo de `TestCase`;
- primeiro teste unitario de validacao.
